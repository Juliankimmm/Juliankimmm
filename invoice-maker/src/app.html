Saving & backups

You do not need to back up every time. Everything — your menu, customers, saved invoices, letterhead and the invoice you are working on — saves automatically, in this browser, on this computer.

Backup makes one file containing everything. Use it to move to another computer or browser, or every few weeks as a safety copy. Restore loads that file back. A restore replaces what is here now.

Keep opening this file in the same browser (e.g. always Chrome). A different browser will not see your saved data.

If you use an invoice folder (below), a full backup is also kept in that folder automatically. To get everything back, press Restore and pick _InvoiceMaker backup.json from the folder.

Invoice folder on this computer

Choose a folder once (for example Documents › Invoices). Every invoice PDF is then saved into it, in a folder for each customer, named by date, e.g. Sung Man Kim / 2026-10-16 Invoice 20260001.pdf. Each customer folder also gets an _Invoice list.csv (opens in Excel) with their details and every invoice's totals. A full backup, _InvoiceMaker backup.json, is kept in the main folder and updated automatically.

Saving into a folder works in Google Chrome and Microsoft Edge. In this browser, PDFs go to your Downloads folder instead. Open this file in Chrome or Edge to use an invoice folder.
